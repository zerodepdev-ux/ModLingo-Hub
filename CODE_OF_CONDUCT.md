# Code de conduite

Ce projet est un endroit pour apprendre, aider et traduire ensemble. Pour que ça reste agréable pour tout le monde, nous attendons de chacun :

## Ce qu'on encourage
- être respectueux et patient, surtout avec les débutants ;
- critiquer les idées et le code, jamais les personnes ;
- assumer ses erreurs et apprendre des retours ;
- reconnaître le travail des autres (traducteurs, auteurs de mods, mainteneurs).

## Ce qui n'est pas acceptable
- harcèlement, insultes, discriminations, attaques personnelles ;
- messages publics ou privés non désirés, spam ;
- publier les informations privées de quelqu'un (adresse, clés, fichiers personnels) sans son accord ;
- encourager le piratage ou le partage de fichiers de jeux ou de mods sans l'accord de leurs auteurs.

## Application
Les mainteneurs peuvent modifier, masquer ou supprimer tout message, issue ou contribution qui ne respecte pas ce code, et écarter temporairement ou définitivement une personne.
Pour signaler un problème de comportement, contacte un mainteneur en message privé via le profil GitHub `zerodepdev-ux`. Les signalements sont traités avec discrétion.
